# 页面悬浮窗使用指南

## ✅ 已完成配置

现在点击扩展图标或按快捷键会在**网页上创建一个独立的悬浮窗**，既不是侧边栏也不是 popup 窗口。

---

## 🎯 悬浮窗特点

### 显示方式
- **独立悬浮**在网页上
- 可以**自由拖拽**到任意位置
- 点击窗口外**不会关闭**
- 需要手动点击右上角 × 关闭

### 外观样式
```
┌─────────────────────────────────┐
│ [⋮⋮] 🌐 即时翻译  [引擎▼] [↔] [×] │
├─────────────────────────────────┤
│ [自动检测] [⇄] [中文▼]           │
│ ┌─────────────────────────────┐ │
│ │ 输入要翻译的文本...          │ │
│ │                             │ │
│ └─────────────────────────────┘ │
│ [粘贴] [翻译]                   │
│                                 │
│ ┌─────────────────────────────┐ │
│ │ 翻译结果将显示在这里...      │ │
│ └─────────────────────────────┘ │
│ [🔊] [📋]                       │
└─────────────────────────────────┘
```

### 尺寸
- **默认宽度**: 320px
- **50% 宽度**: 屏幕宽度的 50%（最大 600px）
- **33% 宽度**: 屏幕宽度的 33%（最大 400px）
- **高度**: 480px（可调整）

---

## 🚀 如何打开悬浮窗

### 方法 1：点击扩展图标
1. 点击浏览器工具栏的即时翻译图标
2. 悬浮窗会出现在当前网页上

### 方法 2：快捷键
按 `Alt + Q`（Mac：`Option + Q`）

---

## 📝 使用功能

### 1. 拖拽移动
1. 鼠标悬停在 Header 左侧的六圆点图标上
2. 光标变为抓取状态 (👆)
3. 按住拖拽到任意位置
4. 释放鼠标

**注意**: 悬浮窗位置会自动保存，下次打开时恢复

### 2. 调整宽度
1. 点击 Header 右侧的宽度调整按钮 (↔)
2. 宽度循环变化：
   - 第 1 次点击：50% 屏幕宽度
   - 第 2 次点击：33% 屏幕宽度
   - 第 3 次点击：恢复默认 320px

### 3. 选择翻译引擎
1. 点击引擎下拉框
2. 选择：
   - **谷歌翻译**: 使用 Google 翻译 API
   - **AI 引擎**: 使用 AI 智能翻译

### 4. 翻译文本
1. 在输入框输入或粘贴文本
2. 选择源语言和目标语言
3. 点击"翻译"按钮
4. 或使用快捷键 `Ctrl/Cmd + Enter`

### 5. 关闭悬浮窗
点击右上角的 × 按钮

---

## 💾 自动保存

悬浮窗会自动保存：
- ✅ **位置** (panelX, panelY)
- ✅ **宽度状态** (widthState)
- ✅ **引擎选择** (engine)
- ✅ **语言设置** (fromLang, toLang)

下次打开时会自动恢复上次的状态。

## 🐛 常见问题

### Q: 点击图标没有反应？
**A:** 
1. 确保扩展已重新加载
2. 刷新网页（F5）
3. 检查 Console 是否有错误

### Q: 悬浮窗打不开？
**A:**
1. 打开开发者工具（F12）
2. 切换到 Console 标签
3. 查看错误信息
4. 截图发给我

### Q: 拖拽不生效？
**A:**
1. 确保按住的是六圆点图标
2. 检查是否在其他元素上释放
3. 刷新页面重试

### Q: 位置没有保存？
**A:**
1. 确保正常关闭（点击 ×）
2. 不要直接刷新页面
3. 检查 chrome.storage.local 权限

## 🔧 技术实现

### 文件结构
```
即时翻译/
├── manifest.json          # 扩展配置
├── background.js          # 后台服务
├── content.js            # 页面脚本
├── floating-window.html  # 悬浮窗界面 ✨ 新增
└── popup.html            # （已弃用）
```

### 工作流程
```
用户点击图标/按快捷键
  ↓
background.js 监听事件
  ↓
注入 content.js 到页面
  ↓
发送消息 jt_open_floating_panel
  ↓
content.js 创建悬浮窗
  ↓
悬浮窗加载 floating-window.html
  ↓
悬浮窗显示在网页上
```

### 消息通信
```javascript
// background.js → content.js
chrome.tabs.sendMessage(tabId, { 
  type: 'jt_open_floating_panel' 
});

// content.js → background.js
chrome.runtime.sendMessage({ 
  type: 'jt_width_changed',
  widthState: 'half'
});
```

## 📱 响应式设计

### 小屏幕适配
- 最大宽度限制为 80vw
- 最大高度限制为 80vh
- 确保在小屏幕上也能完整显示

### 多显示器支持
- 位置信息绝对定位
- 切换显示器时保持相对位置
