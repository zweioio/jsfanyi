## 📝 注意事项

### 1. Popup 的限制
- Popup 模式下，拖拽功能**有限制**
- 浏览器控制 popup 的位置，无法自由移动
- 拖拽主要保存偏移量，实际移动效果不明显

### 2. 如果需要页面悬浮窗
页面悬浮窗（在网页上自由移动的窗口）需要：
1. 在 popup 中发送消息 `jt_open_floating_panel`
2. Content script 接收消息后创建悬浮窗
3. 悬浮窗会在当前网页上显示

### 3. 快捷键行为
- `Alt + Q` 现在打开的是 popup
- 如果需要打开页面悬浮窗，需要在 popup 中添加按钮触发

## 🔧 如果需要页面悬浮窗功能

可以在 popup.html 中添加一个"打开悬浮窗"按钮：

```html
<button id="openFloatingBtn">在页面中打开悬浮窗</button>
```

然后在 popup.js 中添加：

```javascript
document.getElementById('openFloatingBtn')?.addEventListener('click', () => {
  chrome.tabs.query({ active: true, currentWindow: true }, (tabs) => {
    chrome.tabs.sendMessage(tabs[0].id, { type: 'jt_open_floating_panel' });
  });
});
```

这样点击按钮就会在当前网页上创建一个可自由移动的悬浮窗。

## 🐛 如果还是看到侧边栏

### 可能原因：
1. 扩展没有重新加载
2. 浏览器缓存了旧配置
3. 有多个扩展配置文件

### 解决方法：

**方法 1：完全重新安装**
1. 在 `chrome://extensions/` 移除扩展
2. 关闭浏览器
3. 重新打开浏览器
4. 重新加载扩展
5. 测试

**方法 2：清除浏览器数据**
1. 按 `Cmd + Shift + Delete`
2. 选择"缓存的图片和文件"
3. 清除数据
4. 重新加载扩展
5. 测试

**方法 3：检查扩展版本**
1. 在 `chrome://extensions/` 查看版本号
2. 确保是最新版本（1.2）
3. 如果不是，重新加载
