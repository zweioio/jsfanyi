# 插件功能改进计划

## 需求概述

1. **将插件的侧边栏模式改为在当前页面上悬浮**
2. **将翻译引擎左右旋转改为下拉框选择**
3. **新增页面宽度调整功能和拖拽功能**

## 功能详细设计

### 1. 页面悬浮模式

**当前状态：** 侧边栏模式
**目标状态：** 在当前页面上悬浮的独立窗口

**实现方案：**
- 使用 iframe 或 content script 注入方式
- 创建一个可拖拽、可调整大小的悬浮窗容器
- 悬浮窗默认显示在页面右下角
- 支持最小化/最大化切换

**UI 特性：**
- 悬浮窗包含完整的翻译功能界面
- 顶部有标题栏（包含拖拽手柄、最小化按钮、关闭按钮）
- 底部有宽度调整按钮

### 2. 翻译引擎下拉框选择

**当前状态：** 左右切换的 Tab 标签
**目标状态：** 下拉框选择

**实现方案：**
- 将 `.engine-selector` 改为 `<select>` 下拉框
- 选项：谷歌翻译引擎、AI 智能引擎
- 保持现有的引擎切换逻辑不变

**UI 布局：**
```
[Logo] 即时翻译          [引擎选择▼] [≡] [◫]
```

### 3. 拖拽和宽度调整功能

#### 3.1 拖拽图标
- 位置：Logo 前面（header 最左端）
- 大小：20x20px
- 图标：拖拽手柄图标（⋮⋮ 或 ⠿）
- 功能：按住可拖拽悬浮窗到任意位置

#### 3.2 宽度调整按钮
- 位置：header 最右端（引擎选择器右侧）
- 大小：20x20px
- 图标：宽度调整图标（↔ 或 ）
- 功能：点击循环切换宽度
  - 第一次点击：50% 屏幕宽度
  - 第二次点击：33.3% 屏幕宽度
  - 第三次点击：恢复默认宽度

**宽度状态循环：**
```
默认 (300px) → 50% → 33.3% → 默认
```

## 技术实现

### 文件修改清单

1. **popup.html**
   - 修改 header 布局，添加拖拽图标和宽度调整按钮
   - 修改引擎选择器为下拉框

2. **popup.js**
   - 添加拖拽功能逻辑
   - 添加宽度调整功能逻辑
   - 修改引擎选择逻辑

3. **content.js**（需要新增或修改）
   - 创建悬浮窗容器
   - 注入悬浮窗到页面

4. **background.js**
   - 处理悬浮窗的打开/关闭
   - 协调 content script 和 popup 的通信

5. **manifest.json**
   - 确保 content script 权限配置正确

## 注意事项

1. **性能优化：** 拖拽时使用 requestAnimationFrame 避免卡顿
2. **状态持久化：** 所有用户设置都应保存到 chrome.storage
3. **兼容性：** 确保在不同网站上都能正常工作
4. **用户体验：** 拖拽和宽度调整应有平滑的过渡动画

## 预期效果

- 用户可以自由拖拽悬浮窗到页面任意位置
- 一键切换三种常用宽度
- 引擎选择更加直观简洁
- 悬浮窗模式不遮挡页面主要内容
