# 即时翻译

一款 Chrome 翻译插件，集成 **谷歌翻译** 与 **AI 智能翻译（Microsoft Edge Translator）** 双引擎，提供 **Side Panel** 与网页内 **右侧停靠面板** 两种使用方式，并支持挤压网页布局（不遮挡原页面）。

## 核心功能

- **双引擎翻译**：谷歌翻译 + AI 智能翻译；AI 不可用时自动回退谷歌翻译。
- **全局语言选择**：一套“翻译语言 / 目标语言”在三个 Tab 间共享。
- **文本翻译**：输入框 + 一键粘贴、翻译、复制、语音朗读。
- **回译核对**：自动将译文回译为源语言，便于核对语义是否准确。
- **网页划词快捷翻译**：在网页中选中文本，面板内即时显示翻译结果。
- **网页对照翻译**：支持“双语对照 / 仅查看译文”（Beta）。
- **可调宽度停靠面板**：拖动面板左侧边框调整宽度，并支持宽度预设（默认 360px / 50% / 30%）。
- **历史记录与缓存**：保存最近翻译记录，并对翻译结果做缓存提升响应速度。

## 使用方式

- **打开停靠面板**：点击插件图标（或使用快捷键 **Alt+Q**）。
- **调整宽度**：拖动面板左侧边框。
- **切换翻译引擎**：使用面板顶部右侧的引擎下拉框。
- **选择语言**：在 Tab 选项上方的全局语言选择栏中设置“翻译语言 / 目标语言”。

## 安装（开发者模式）

1. 打开 `chrome://extensions/`，开启右上角 **开发者模式**。
2. 点击 **加载已解压的扩展程序**，选择 [`extension`](file:///Users/apple/Desktop/即时翻译/extension) 文件夹。
3. 打开任意网页，点击插件图标即可使用。

## 项目结构

- [`extension`](file:///Users/apple/Desktop/即时翻译/extension)：Chrome 插件源码（Manifest V3）
- [`website`](file:///Users/apple/Desktop/即时翻译/website)：官网展示页资源

## 开发提示

- 在 `chrome://extensions/` 里刷新扩展后，仍需 **刷新目标网页** 才会重新注入更新后的内容脚本。
