常见问题

关于即时翻译的一切疑问

什么是双向回译核对？

双向回译核对是一种验证翻译准确性的方法。当你将一段文字从中文翻译成英文后，系统会自动将这个英文译文再次翻译回中文。通过对比原文和回译的结果，你可以直观地判断翻译是否准确表达了原意。

支持哪些语言？

即时翻译目前支持中文、英文、日文、韩文、法文、德文、西班牙文、俄文等主流语言的双向翻译。我们持续扩展支持更多语言。

翻译结果会存储吗？隐私安全如何保障？

我们高度重视用户隐私。所有翻译内容仅用于实时翻译，不会被存储在我们的服务器上，也不会用于任何其他目的。

免费版有使用限制吗？

免费版包含所有核心功能，没有翻译次数限制、没有字符数限制，你可以无限制地使用双向回译、滑词翻译和网页对照翻译。

除了 Chrome 还支持其他浏览器吗？

目前我们主要支持 Chrome 浏览器。由于 Edge、Brave 等浏览器兼容 Chrome 扩展，理论上也可以在这些浏览器上使用。
